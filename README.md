# Spider Nexus — Interactive React Website

An unofficial cinematic Spider-Man fan interface built with React, Vinext/Next-compatible routing, TypeScript, Tailwind CSS, custom CSS animation, Canvas particles, and accessible UI primitives.

## Included

- Full-screen spotlight mask-reveal hero
- Pointer, touch, idle-orbit and reduced-motion behavior
- Canvas particles and web-like connection lines
- Responsive glass navigation and mobile drawer
- Interactive ability selector
- Multi-section cinematic image archive
- Optional Web Audio interface feedback
- Local bundled image assets
- Responsive desktop, tablet and mobile layouts

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Production build

```bash
npm run build
npm run start
```

## Main files

- `app/page.tsx` — components, interactions and content
- `app/globals.css` — visual system, responsive design and animation
- `app/layout.tsx` — metadata and document wrapper
- `public/spider-hero.png` — hero reveal image
- `public/spider-city.png` — city patrol image
- `public/spider-final.png` — vertical action image

This is a frontend-only project. It does not require a database, API keys or a backend server beyond the framework's local runtime.
